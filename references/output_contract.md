# Output Contract

Formal output is one HTML report plus one Markdown working draft.

```text
评价洞察Skill-正式输出/
├── 评价洞察到经营动作报告.html
└── 评价洞察到经营动作报告.md
```

Intermediate CSV, JSON, screenshots, and audit files may exist in the work directory, but not in the formal output directory.

## Required HTML Sections

1. 首屏 Dashboard
2. 证据可信度
3. 报告闭环
4. 结论总览
5. 样本覆盖
6. 洞察与机会评分
7. VOC 原声证据
8. 可执行动作矩阵
9. 主图表达 Brief
10. 详情页优化 Brief
11. 客服 FAQ 预案
12. 产品改进优先级路线图

## Formal Artifact Positioning

- HTML is the polished delivery report.
- Markdown is the editable working draft for knowledge-base storage and revision.
- Main-image, detail-page, FAQ, and roadmap briefs are embedded in the HTML instead of emitted as separate formal files.

## Forbidden Formal Output

- Public-content planning notes such as `适合公众号截图`.
- Unsupported category certainty.
- Fake shop names, links, sales, rankings, or industry claims.
- Raw buyer nicknames in public examples.
- Absolute local paths inside public HTML.
